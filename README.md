# dten-speed

Internet speed test from the terminal, for people and for AI assistants, by [Dten](https://dten.com.br).

It measures the download and upload of **this computer's** connection with the same engine as the
[Real Net Speed](https://play.google.com/store/apps/details?id=br.com.maishub.speedmonitor) app and the
[dten.com.br](https://dten.com.br) web meter. Free, no account.

## Status

**Not released yet.** This repository holds the signed releases of the `dten-speed` binaries for
Linux, macOS and Windows. The first release, the npm package and the install scripts will be announced
here and at [dten.com.br](https://dten.com.br). Until then, measure in the browser at
[dten.com.br](https://dten.com.br).

## What each release will contain

- `dten-speed` binaries for `linux-x64`, `linux-arm64`, `macos-arm64`, `macos-x64` and `windows-x64`;
- `SHA256SUMS`, the checksum of every binary, and `SHA256SUMS.minisig`, its [minisign](https://jedisct1.github.io/minisign/) signature.

The source code is not in this repository.
